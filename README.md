# fishgraph

核力式力导向图布局算法。零运行时依赖，TypeScript，vitest 测试。

图由**节点**（圆/椭圆/矩形，可带文字）与**连线**（可带文字）构成。布局不是"弹簧-电荷"
的经验堆叠，而是一个**保守力场**：所有力都从同一个能量泛函求梯度得到（力 = −∇E），
求解器沿能量下降方向弛豫，能量单调不增，必然收敛。

## 安装与运行

```bash
npm install
npm test          # vitest 全量测试（~2 分钟）
npm run typecheck

```

## 物理模型

记节点 i、j 的**表面间隙** `g = |pᵢ − pⱼ| − rᵢ − rⱼ`（中心距减两个包围半径），
`m = mᵢ·mⱼ` 为质量积，L = `naturalLength`。

### 1. 节点间斥力 —— 核力式，有限作用域

```
g ≥ R（R = 2L）:  E = 0,  F = 0
gFloor ≤ g < R:   E = ½·k_r·m·(1/g − 1/R)²      F = k_r·m·(1/g − 1/R)/g²
g < gFloor:       接触弹簧线性延拓（穿透越深推力越大，力与能量严格一致）
```

- **近距陡增**：g → 0 时主项回归 `k_r·m/g³`，保证节点永不重叠；
- **脱接触即归零**：在作用域边界 `g = R` 处能量与力**同时**光滑归零（C¹ 连续）。
  脱离接触的节点互不干扰——远端节点堆不会把某节点的连线"挤"到同一侧，
  整个图的覆盖面积天然趋紧凑；
- `k_r = 2L·k_a` 的取值使**无张力时相邻平衡间隙恰为 L**。

### 2. 连线引力 —— 万有引力式（仅相邻节点对）

```
F_a = k_a·m/g²          E_a = −k_a·m/g        （长程，截断处常力延拓防发散）
```

没有连线的节点对**没有**这项。平衡位置由 斥力 = 引力 决定：g* ≈ L。

### 3. 线性张力 —— "连线越长能量越大"

```
F_t = k_t·g             E_t = ½·k_t·g²        （仅间隙中的线长；节点内部不贡献）
```

拉力随线长线性增强、能量二次增长。`edgeTension` 的语义：g = L 时张力是引力的倍数。
直线天然最优——任何弯曲都拉长 g 之和、抬高能量，所以"线趋向短而直"不需要单独建模。

### 4. 弱基础引力 —— 非相邻节点对

两种模式：

- `pairwise`：`F_w = k_w·m/g²`（k_w ≪ k_a）。平衡间隙 `g = 1/(k_w/k_r + 1/R)`
  —— 陌生人比朋友远，但**饱和于斥力作用域 R**，无限远的孤立对不受任何力；
- `centroid`（默认）：全对调和约束 `F = k_harm·m·d`，数学上等价于每个节点
  受"朝质心的简谐束缚"，合力/合力矩恒为零。孤立点保持紧凑对称而不飞散。

### 5. 边-节点避让软墙 —— "线被节点遮盖产生强斥力"

对每条边 [A,B] 与非端点节点 C（表面到线段距离 h，作用距离 ρ = 0.15L）：

```
h < ρ:  F = k_en·(ρ − h)/ρ       E = ½·k_en·(ρ − h)²/ρ
```

线性软墙在 h = ρ 处光滑归零；全压强度约为键合力的 `10 × edgeNodeRepulsion` 倍——
足以坚决推开压线节点。反作用力按投影重心坐标分摊给线段两端（**线也会让路**）。

### 6. 边文字软墙 —— "文字多少自动撑开距离"

边中点的文字包围盒是软障碍（margin = 0.04L 的线性软墙），把两端节点撑到恰好
容纳文字。长文字按**占用面积最小**回绕：枚举行数 k，贪心断行（拉丁词不拆、
CJK 逐字断），取包围盒面积最小者。

## 求解器

无摩擦、不"卡住"：位置直接沿力方向弛豫（信任域步长 + 回溯线搜索），
能量单调不增。收敛判据是力残差 `max|F|/forceUnit < ε` 连续若干步。

**分阶段弛豫**（对应人工排图的直觉）：

| 阶段 | 启用的力 | 预算 |
|---|---|---|
| 0 | 节点斥力 + 弱引力（先把节点摆开） | 35% |
| 1 | 加入连线引力与张力（收缩成骨架） | 30% |
| 2 | 加入边-节点避让、边文字软墙 | 20% |
| 3 | 节点文字生效（节点变大）微调 | 15% |

**性能**：节点-节点力用 Barnes-Hut 四叉树（双树遍历 + 保守聚合，
力/能量仍是同一泛函的精确梯度）O(n log n)；避让对用均匀空间网格。
2000 节点压力测试在秒级完成。`accuracy: 'exact'` 为 O(n²) 参考实现，
两者结果一致性有测试保证。

## API

```ts
import { ForceLayout } from 'fishgraph';

const layout = new ForceLayout(
  {
    nodes: [{ id: 'a', shape: { kind: 'rect', w: 120, h: 40 }, label: '开始' }],
    edges: [{ source: 'a', target: 'b', label: 'PASS' }],
  },
  { naturalLength: 120, edgeNodeRepulsion: 3, seed: 42 },
);
const r = layout.run({ maxIterations: 20000 });
layout.positions;   // Map<id, {x,y}>
layout.energy;      // 当前总能量
r.converged;        // 力残差判据
```

实时调参（demo 用）：`layout.updateOptions({...})` 保留坐标继续弛豫；
`layout.fix(id, x, y)` / `unfix(id)` 拖拽节点。

## 参数调优

| 参数 | 默认 | 作用 |
|---|---|---|
| `naturalLength` | 120 | 一切尺度的锚：平衡边长 = 它，斥力作用域 = 2×它 |
| `edgeTension` | 0.1 | >0 让长边额外收缩；过大时会把多跳路径压成叠线 |
| `edgeNodeRepulsion` | 3 | 压线推开力度；大矩形+回环枢纽的图可加到 10–20 |
| `weakGravityRatio` | 0.2 | pairwise 模式陌生人间距（饱和于 2L）；越大越远 |
| `gravity` | centroid | 多个不相关分量想保持紧凑用 centroid；想让分量自由分形用 pairwise |
| `labelCollision` | true | 关掉后边文字不再参与力学 |
| `accuracy` | barnes-hut | n < ~300 或要逐位复现用 exact |
| `init` | bfs | 度数优先逐层摆放；小对称图遇局部极小可试 random |

## 测试

`tests/layout.test.ts`：物理平衡（平衡间隙解析解）、能量单调、确定性、
压线推开、BH/exact 一致性、规模 5→2000、成群/离散比例混合、
五个构型场景（S1 自由自然形、S2 全连接等同形、S3 品字/菱形、
S4 方形贴合、S5 文字撑开+最小面积回绕）。

`tests/mermaid.test.ts`：19 节点真实流程图（Quality Gate 分支 + 回环），
断言收敛、零重叠、零线穿节点，并渲染 `output/mermaid-layout.svg` 供目视比对。
