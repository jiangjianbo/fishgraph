# fishgraph

纯网格图布局引擎。零运行时依赖，TypeScript，vitest 测试。

图由**节点**（圆/椭圆/矩形，可带文字）与**连线**（可带文字）构成。布局全程在
离散网格中一次算定——无力学、无迭代、确定性重放：**波纹放置 → 中心对称膨胀 →
通道约束压实 → 网格 A\* 避障走线**，成行成列与无重叠由构造保证。

## 安装与运行

```bash
npm install
npm test          # vitest 全量测试
npm run typecheck
npm run demo      # 交互式 demo（vite，http://localhost:5173）
```

## 布局流水线（grid-undirected，唯一主引擎）

| 阶段 | 职责 | 关键规则 |
|---|---|---|
| 1. 质点波纹放置 | 所有节点视为 1×1 质点，从度数最高的种子按 BFS 层序一圈圈向外生长 | 评分 = 曼哈顿张力 − 环周长奖励 + 环内方位分类（十字 < 45° 对角 < 杂角）；平局按扫描序（先填满一行再开新行）；死锁插行列 100% 不死锁 |
| 2. 中心对称膨胀 | 节点按文字/形状物化为 w×h 格 AABB | 质点格恒为 AABB 中心格（奇数精确居中、偶数向左/上配平半格）；插行列让位 |
| 3. 通道约束压实 | 相邻占用行/列空隙归一 | 恰好留 channelMargin 格走线走廊，成行成列 |
| 4. A\* 避障走线 | 每条边在自由通道格中正交寻路 | 拐点惩罚；节点位置不被走线反向推开 |

### 流动方向（direction）

- `'none'`（默认）：无向波纹放置。
- `'TB'` / `'LR'`：有向层级布局——解环（DFS 反馈边）+ 最长路径分层，节点钉在
  自己的层级行/列上，所有边**顺流无逆边**（TB：target 在 source 下方或同层下游）。

## 设计原则

- **简单规则驱动，底层逻辑无例外**：布局只由少数局部规则（张力、环闭合、
  方位分类、层级行）决定，不针对任何特定图结构写特例、不做结构识别豁免。
  形状契约与规则的关系见 `doc/布局核心原则.md`。
- **确定性**：同一组输入逐位重放（固定 seed，放置/评分/平局全固定规则）。
- **形状契约测试化**：用户口径的形状验收（矩阵、品字、正方形、十字星、
  顺流山形等）固化为 `tests/shape-contract.test.ts` 硬性用例。
