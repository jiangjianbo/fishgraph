# 布局核心原则

> fishgraph 布局引擎的总设计：美学目标、元规则、力学原则、流水线骨架与
> 策略接缝。一句话哲学：**拓扑优先于几何，节点与布线解耦；离散网格定
> 骨架，波纹生长成方阵，正交走线留通道。**

## 0. 文档定位

本文档回答"布局引擎由什么统治"——目标、规则与阶段职责，不回答
"具体怎么算"。与详细设计的分工边界：

| 内容 | 本文档（总设计） | layout-*.md（详细设计） |
|---|---|---|
| 规则陈述与设计动机 | ✅ 唯一陈述处 | 只引用，不复述 |
| 实现口径、参数值、函数与文件名 | ✗ | ✅ |
| 实测案例与回归细节 | 仅示例级 | ✅ |
| 实现状态与待办 | 仅 §8 集中 | 「当前边界」节 |
| 变更史 | ✗（进 `操作日志.md`） | ✗（进 `操作日志.md`） |

**引用规范**：引用本文档一律用章节号（如「布局核心原则 §3.7」），不用
小节标题措辞——标题措辞可改，章节号一经发布不再变更。

相关文档：[architecture.md](./architecture.md)（模块职责与数据流）、
[layout-grid-undirected.md](./layout-grid-undirected.md)（唯一主引擎
详细设计）、[layout-circle.md](./layout-circle.md)（策略接缝最小示例）。

**术语表**：

| 术语 | 含义 |
|---|---|
| 质点 | 1×1、无面积的节点表示；放置阶段节点的唯一形态 |
| 格 | 布局的最小空间单位；1 格 = 尺寸映射策略产出的矩形基准格（x/y 两轴独立，配置 `cellW`/`cellH`） |
| 格 AABB | 节点物化后的占格矩形（gw × gh 格） |
| 格距 | 基准格的物理尺寸；连续坐标 = 格坐标 × 格距 |
| 走廊（通道） | 相邻占用行/列之间预留给连线的空隙，宽度 = 配置 `channelMargin`（格） |
| 层级行 | 有向模式中同一层级节点锚定的行 |
| 契约 | 以测试硬性验收的形状期望（严格矩阵、品字、十字、山形等） |
| 作用域 | 折叠模式中一次独立布局的范围（root + 每个容器一个） |

## 1. 问题与目标

**输入**：图规格——节点（可带声明形状与文字）、连线、可选 subgraph
分组。**输出**：每个节点的二维位置与物化尺寸（格 AABB）、每条连线的
走线拐点。布局在**构造期一次算定**：无迭代收敛过程、无随机性，同输入
逐位重放。

美学目标与其验收口径：

| 目标 | 含义 | 验收口径 |
|---|---|---|
| 均匀分布 | 节点沿已填区域边界一圈圈铺开，不挤压成团 | 全局严格成行成列 |
| 结构对称 | 对称图产出对称布局 | 形状契约硬性测试 |
| 紧凑填充 | 相关节点贴近、最小面积 | 张力评分 + 压实回收空白 |
| 无压线无共线 | 连线不穿节点、同起点连线不重合 | 放置层构造性排除 |
| 方向流动感 | （有向）边顺流、层级清晰 | 顺流无逆边、层级行锚定 |

**无重叠不是美学目标而是硬约束**（§3.3）——它没有权衡空间，违反即
非法。

## 2. 最高原则（元规则）

元规则不直接参与计算，它统治其余所有规则的组织方式与冲突裁决。

### 2.1 布局只由少数局部规则决定

每条规则都是局部、可独立陈述的，不依赖对全局结构（星形/树/矩阵……）
的识别。当前生效的规则全集（唯一清单，其余章节引用规则一律用编号；
实现口径、参数与函数见详细设计）：

| # | 规则 | 陈述 | 类别 | 生效位置 |
|---|---|---|---|---|
| R1 | 波纹生长 | 候选按到种子的跳数 FIFO 出队，放置沿已填区域边界一圈圈向外扩张 | 放置序 | §4.2 |
| R2 | 张力 | 候选格到全部已放置邻居的曼哈顿距离和最小者优先（贴邻最近） | 评分项 | §4.2 |
| R3 | 环周长奖励 | 与已放置节点成环时，选使环几何周长/包围盒最小的位置（封角） | 评分项 | §4.2 |
| R4 | 环内方位分类 | 边走向优先落在邻居的十字（水平/垂直）方位，45° 对角次之，杂角再次；只在张力同分的候选间裁决 | 平局序 | §4.2 |
| R5 | 扫描序平局 | 得分相等的候选按行优先的扫描序裁决（先填满一行再开新行） | 平局序 | §4.2 |
| R6 | 连线零共线 | 同起点两条连线夹角 ≠ 0（180° 反向允许） | 硬约束 | §4.2 |
| R7 | 连线零压线 | 连线线段不途经第三节点 | 硬约束 | §4.2 |
| R8 | 死锁插行列 | 搜索预算内无合格空格、或最佳候选质量差于死锁阈值（无向按贴邻距离和计）时，动态插入一行/列挤出新空间 | 兜底 | §4.2 |
| R9 | 层级行锚定 | 有向模式：节点锚定在其层级行附近，方向罚抑制逆流 | 有向评分 | §5 |

### 2.2 无例外、无特例

不针对特定图结构做结构识别与规则豁免。**形状契约必须是规则的涌现结果**：若某契约与某规则物理互斥，修改**契约**（换验收形状，或改由无向模式验收），而不是给引擎开口子。实例：有向 TB 顺流与"十字星"互斥（十字必有一条边逆流）→ 契约改由"顺流山形"验收（§5）。

### 2.3 引擎收敛

`grid-undirected` 是唯一主引擎：方向语义由 `direction`（`'none' | 'TB' | 'LR'`）在同一流水线内承载（§5），不设第二条流水线。`circle` 仅作为策略接缝的最小示例保留。

### 2.4 规则冲突时的裁决顺序

1. **硬约束不可违反**：无重叠、R6、R7 没有权衡空间。空间不足时扩展空间（R8），永不放宽约束。唯一例外是极端拥堵下的**放置完成性优先**：死锁解法落位后不做共线/压线的二次复查，孤立节点全部候选被禁时宁压线也完成放置——残留违例由阶段 4 消压线与阶段 8 走线避障兜底（§4.4、§4.6）。
2. **软目标在硬约束之后最大化**：层级感、紧凑、对称都是软目标。拥堵处允许层级行偏离 1~2 行，优先保证无重叠与最小周长环（§5）。
3. **平局按固定序裁决**：候选同分时按 R5 扫描序裁决，保证确定性重放。
4. **契约与规则互斥时改契约**（§2.2）。

## 3. 核心力学原则

八条力学原则解释"布局为什么长这样"。每条固定格式：陈述 → 动机 →违反后果 → 构造保证；生效规则引用 §2.1 编号。

### 3.1 节点与布线两阶段解耦

- **陈述**：布局只决定节点位置。连线在全程不占空间——放置阶段仅作为拓扑引力（决定谁挨着谁），走线在节点定型后让出的自由通道中进行。
- **动机**：连线若占空间，节点与连线互相约束，极易"线锁节点"死锁；解耦后节点布局是纯节点问题，走线是其后的独立寻路问题。
- **违反后果**：死锁；布局被连线几何绑架。
- **构造保证**：R2/R3 评分只按节点间距离计，不含线段几何（§4.2）；阶段 8 走线只寻路、不推节点（§4.6）。

### 3.2 核心骨架优先

- **陈述**：度数越高的节点越先放置：度数最高者为种子、占据网格中心；度数只决定种子与新连通分量的归属，不决定全局排列顺序（排列由 R1波纹生长决定）。
- **动机**：高度数节点是全局拓扑骨架；先立骨架，低度数节点后期挂载到已有结构上，避免边缘节点打乱全局结构。
- **违反后果**：边缘节点先占好位，核心节点被挤到外围。
- **构造保证**：§4.2 放置序。

### 3.3 无重叠与避让（硬约束）

- **陈述**：三条禁令，全部在放置层**构造性**排除：
  1. 节点-节点不重叠；
  2. 节点-连线不重叠（R7 零压线）：任何连线线段不途经第三节点——不管未来用什么风格画线（直线/折线/贝塞尔），都必须在放置层禁止；
  3. 同起点连线不共线（R6 零共线）：同起点两条连线夹角 ≠ 0，180°反向允许。
- **动机**：可读性底线。压线与共线在任何画线风格下都不可读，不能依赖事后修正。
- **违反后果**：连线穿节点、多线重合，图不可读。
- **构造保证**：无重叠由三段构造排除——阶段 2 每格一节点的占用检查、阶段 3 带内推挤让位、阶段 5~7 通道下限；R6/R7 在 §4.2 候选评估中排除。

### 3.4 均匀分布

- **陈述**：节点沿已填区域边界一圈圈向外均匀扩张、铺满可用平面。均匀性由**离散构造**保证（波纹生长 + 每格一节点），不是力学平衡的结果。
- **动机**：美学目标"均匀分布"；离散格占用让均匀性成为构造性质而非优化目标，无需调参。
- **违反后果**：拥挤团块与大片空白并存。
- **构造保证**：R1（§4.2）+ 阶段 5~7 行列整理回收空白（§4.5）。

### 3.5 张力收缩

- **陈述**：相连节点趋于贴近。放置评分中体现为张力项：候选格到全部已放置邻居的距离和最小（R2）。距离维全权由张力承担。
- **动机**：美学目标"紧凑"；连线像橡皮筋，关联节点自然聚拢。
- **违反后果**：相关节点散落、连线拉长、面积膨胀。
- **构造保证**：R2（§4.2）。

### 3.6 最小周长环

- **陈述**：新节点与已放置节点构成环时，优先选使环几何周长（或包围盒）最小的位置（R3）。
- **动机**：已放置节点位置刚性高，新节点被拉入最紧凑的面内。
- **违反后果**：环被拉成长条，出现长边穿透。
- **构造保证**：R3（§4.2）。

### 3.7 质点化与通道式膨胀

- **陈述**：放置阶段所有节点（含 subgraph 容器）都是 1×1 无面积质点；节点定型后按真实尺寸膨胀为格 AABB，物化的同时为走线拉伸出走廊。
- **动机**：尺寸不是拓扑属性——放置期携带尺寸会让大节点撕裂布局；先定拓扑再物化，且物化与扩容通道是同一次空间拉伸（§4.3/§4.5）。
- **违反后果**：大节点在放置期挤乱全局；无走廊可走线。
- **构造保证**：§4.2 全质点；§4.3 中心对称膨胀（质点格恒为 AABB 中心格）+ 带内推挤；§4.5 压实统一走廊。节点尺寸与格数由尺寸映射策略供给（§6.1）。

### 3.8 长尾卷起与逻辑聚类

- **陈述**：度 1 长尾与度 2 长链可收缩为 SuperNode 参与骨架布局，定型后再释放展开。仅在折叠流水线中启用（§6.3）；默认非折叠流水线不卷起。
- **动机**：长尾散点会打乱全局布局；卷起后骨架先定型。
- **违反后果**：长尾把布局拉成长条。
- **构造保证**：折叠流水线的阶段 1 折叠与阶段 3 展开（§6.3）。

## 4. 流水线骨架

流水线按十个阶段展开：阶段 0~3 是拓扑与物化主链，阶段 4~7 是物化后
整理（把膨胀网格归一为可走线的走廊网格），阶段 8~9 是走线与出口；
折叠是可选前置。全程整数格运算：

```
[0 尺寸分级] → [1 折叠预处理(可选)] → [2 拓扑粗布局] → [3 节点膨胀物化]
→ [4 膨胀后调整(消压线)] → [5 行列扫描合并] → [6 走廊插入] → [7 通道压实]
→ [8 走线] → [9 物理化与渲染出口]
```

阶段间数据契约：**基准格与格数 → 格坐标 → 格 AABB → 走廊网格 →
拐点序列 → 世界坐标可渲染图**。有向模式仅替换阶段 2 的放置美学
（§5），其余阶段完全共用。各阶段实现状态统一见 §8。

### 4.1 预处理（阶段 0~1）

**阶段 0：尺寸分级**（§6.1 正向）：节点度量（形状声明 ∨ 文字盒，
文字按面积最小折行）→ 宽/高独立锚定聚类分级 → 矩形基准格 + 各节点
宽/高格数。格单位自本阶段起贯穿全程，本阶段是「px 盒 → 整数格」的
唯一换算点。

**阶段 1：折叠预处理（可选）**：识别度 2 长链与 subgraph 容器、收缩
为视图项、构建作用域树（root + 每容器一个作用域）；其后阶段 2~7 在
各作用域内逐级执行，展开是纯刚性平移（§6.3）。默认关闭——非折叠
流水线不做卷起（§3.8）。

### 4.2 阶段 2：拓扑粗布局（质点放置）

- **职责**：决定放置序与每节点的整数格坐标。全图 1×1 质点、每格至多
  一节点。
- **放置序**：R1 波纹生长。排列不由度数降序决定：对称图上多个高度数
  节点会形成朝相反方向生长的前锋、把矩阵图折叠——所以度数只定种子与
  分量归属，排列交给波纹。
- **候选评估**：R2 张力 + R3 环周长评分（只按格距离计，连线零占位）；
  R4 方位分类与 R5 扫描序在平局间裁决；R6/R7 禁令直接排除不合格
  候选。平局能量、"环 0 候选"等实现口径见详细设计。
- **死锁兜底**：R8，保证 100% 不死锁。
- **subgraph 与影子投影**：subgraph 子作用域使用局部坐标系独立布局。
  与子图内部节点有连线的外部节点，以其**影子节点**参与子作用域的
  布局计算：影子坐标 = 外部节点在其宿主作用域放置帧中相对容器的
  投影，一经确定**固定不变**——放置逻辑不得改写它（实现上对坐标
  设置免疫）。影子只通过锚点牵引所连内部项（决定子图朝向与包裹
  尺寸），不占格、不参与死锁判定与插行列推挤。
- **例外**：连线文字虚拟节点占格未实现（§8）。

### 4.3 阶段 3：节点膨胀（物化）

- **职责**：把 1×1 质点膨胀为 gw × gh 格 AABB，物化真实尺寸。
- **机制（概念）**：**中心对称**——质点格恒为 AABB 中心格（偶数尺寸
  固定向左/上配平半格）；**带内推挤**——水平推挤只扰动目标行带内的
  元素、垂直推挤只扰动目标列带内的元素，其余行/列不受扰动；被推元素
  整体平移、级联封闭，元素 AABB 全程完整不撕裂。
- **subgraph**：容器尺寸依赖嵌套子图尺寸，自内向外先算。
- **折叠模式**：卷起的长尾与子图在此展开物化（§6.3）。

### 4.4 阶段 4：膨胀后调整（消压线）

- **职责**：全部节点膨胀完成后，以真实格 AABB 为单元做一次全图再
  布局（让位调整），消除「质点判定 → 物化尺寸」之间的口径落差。
- **动机**：R6/R7 与 §3.3 在阶段 2 按 1×1 质点判定；膨胀使元素突然
  加宽，原有的节点间中心连线可能落进变宽后的第三方 AABB（压线）。
  此阶段对压线的第三方元素沿背离连线方向迭代推离（扫掠级联让位），
  恢复硬约束口径。
- **约束**：调整是让位不是重排——保持膨胀后的相对方位；迭代有界，
  残留的个别压线由阶段 8 走线避障兜底（A* 不穿 AABB）。
- **折叠模式**：在各作用域内以视图项为单元执行（容器不入判定），
  展开为纯平移不受影响。

### 4.5 阶段 5~7：行列整理与通道压实

三个子步骤把膨胀网格归一化为均匀走线走廊：

1. **行列扫描合并（阶段 5）**：扫描全网格，尽量合并可合并的行/列，
   分两个动作：
   - **收紧**：回收全部多余空行空列（间隔 >1 的相邻占用行/列收紧为
     贴邻）；
   - **对齐**：把独居元素（所在列/行线上没有其他元素）吸附到邻近
     主线（已有 ≥ 2 个元素的列/行线），使可并线的散落元素对齐成列/
     成行。候选主线按距离升序尝试（平局取更靠近布局重心者），平移
     后与他者重叠或扩大包围盒则放弃该候选。异宽元素对齐的是格线
     （左缘对齐），同宽元素即中心对齐。
   约束：合并不得违反 §3.3 的无重叠——不产生元素重叠。对齐会改变
   中心连线几何、可能引入个别压线，由阶段 8 走线避障兜底。
2. **走廊插入（阶段 6）**：每对相邻占用行/列之间确保至少一个空行/
   空列（不足则插入），使任何相邻元素之间都存在走线通道。
3. **通道压实（阶段 7）**：把所有间隙统一到通道宽度 `channelMargin`
   （不足补出、超出回收）；压实后全局严格成行成列，不破坏相对方位、
   不产生重叠。

收紧、走廊插入与压实同为单轴保序重映射（阶段 5 收紧 + 阶段 6 与
阶段 7 是同一重映射的分段分解，最终状态一致）；对齐合并是逐元素的
无碰撞平移，同样不破坏元素 AABB 连续性——全部动作无重叠由构造保证。

### 4.6 阶段 8：走线

- **职责**：在自由通道格中为每条边寻路，输出走线拐点序列；**不修改
  节点位置**（§3.1）。
- **机制（概念）**：网格避障寻路（正交、拐点计价）；端点锚定在两端
  端口主导侧；障碍 = 全部节点格 AABB。无可行正交路径时空间原语层
  **显式失败**（不静默产出穿墙解），策略层降级为两端直线兜底（极端
  贴邻场景）。
- **无弛豫**：网格解即最终解。节点位置一旦物化不再被走线反向推开——
  无重叠已由构造保证（§3.3），无需事后修正。
- **风格**：连线最终形态（端口/端帽/路径风格/转角/交叉、通道内平行线
  间距）由连线风格策略承担（§6.2）。

### 4.7 阶段 9：物理化写回与渲染出口

- **职责**：格解（节点格 AABB + 边格走线）交给尺寸映射策略反向
  （§6.1），产出世界坐标可渲染图；写回元素（位置/尺寸）与边
  （走线拐点）。
- **口径**：连续坐标 = 格坐标 × 格距，整体平移质心归零；px 至此才
  出现且只存在于出口——布局与存储全程只认整数格（§6.1）。

## 5. 方向语义（direction: 'none' | 'TB' | 'LR'）

方向语义不是独立流水线：三值共用同一引擎，仅阶段 2 的放置美学不同，其余阶段完全共用（§2.3）。

- **'none'（默认，无向）**：§4.2 的波纹放置，位置自由寻优。
- **'TB' / 'LR'（有向）**：
  1. **解环**：DFS 识别反馈边（回边），布局时临时忽略（不翻转、不参与分层与流向约束），图转化为 DAG；
  2. **分层**：DAG 上按拓扑序做最长路径分层，源点在第 0 层；
  3. **层级引导放置**：候选以已放置邻居坐标与理想层级行为锚（R9），层级偏离罚 + 方向罚使节点顺流落位；开阔处几乎总在同行，拥堵处允许偏离 1~2 行（§2.4 裁决 2）；层级行本身不被插行列推动（TB 插列、LR 插行）。
- **验收口径**：所有边顺流无逆边。方向感由放置层构造保证，无弛豫。
- **契约实例**：十字星与顺流物理互斥 → 契约改由"顺流山形"验收（§2.2）。

## 6. 横切策略接缝

四个可替换维度，全部与主流程正交：

| 接缝 | 配置入口 | 概念职责 | 详见 |
|---|---|---|---|
| 方向语义 | `direction` | none/TB/LR 同一流水线 | §5 |
| 尺寸映射 | `metric`（注册/热切换） | 节点度量 ↔ 格单位、逻辑格 → 可渲染图 | §6.1 |
| 连线风格 | edge 策略族 | 连线的最终视觉形态 | §6.2 |
| 折叠 | `folding` 开关 | 长尾与容器的可选卷起预处理 | §6.3 |

### 6.1 尺寸映射（metric）

逻辑布局与现实尺寸的映射是独立可替换策略。同一策略在两个方向被
消费：

| 方向 | 消费方 | 职责 |
|---|---|---|
| 正向（供布局） | 逻辑布局 | 节点度量（形状声明 ∨ 文字盒，文字按面积最小折行）→ 宽/高**独立**锚定聚类分级 → 矩形基准格 + 各节点宽/高格数（格数 = 盒 ÷ 基准格，向上取整） |
| 反向（供渲染） | 渲染出口 | 逻辑格解 → 世界坐标可渲染图（节点 AABB / 容器实占 / 边拐点，纯数据）；渲染端拿自由坐标自行缩放绘制，不感知网格 |

- **矩形格口径**：1 格 = 最小基准盒（x/y 两轴独立）；节点物理尺寸 =格数 × 格距，大小节点的尺寸比例真实化；节点间隙由通道宽度（格）控制，与节点尺寸解耦。
- **格是主单位**：布局与存储只认整数格，px 仅为内存中间量。
- 宽高比定不出格数（2:1 可以是 2×1 也可以是 4×2），必须靠绝对尺寸分级——这是"宽/高独立聚类"的根由。
- **接口预留**（默认实现 = 现状口径）：折行平局判据（周长）、行距系数、字体族测量、聚类方式、物理化相位与归零方式。

### 6.2 连线风格（edge 策略族）

连线"长什么样"与布局解耦：策略族只消费布局输出（节点位置/尺寸、走线拐点），不反哺布局。六个正交维度：

| 维度 | 职责 |
|---|---|
| 端口 | 端点对接位置（固定四点/同侧均匀分布），起、终端独立配置 |
| 贴合 | 端口贴到元素真实几何（AABB/声明形状/包围圆/中心） |
| 端帽 | 两端装饰（无/箭头/圆点），起、终端独立配置 |
| 路径 | 线的形状（直线/折线/贝塞尔/斜折线分散） |
| 转弯 | 拐点形态（尖角/圆角） |
| 交叉 | 平交/立交（跳线弧） |

管线装配与端口分组规则见 architecture.md；通道内跨边平行线的等距分流待办（§8）。

### 6.3 折叠（folding）

可选预处理，开启后流水线变为：**折叠**（链与 subgraph 收缩为视图项）→ **各作用域独立跑 §4 流水线** → **纯刚性平移展开** → 物理化 + 走线。

- **作用域隔离**：让位与插行列只发生在作用域内部、以视图项为原子单元；展开是唯一落位动作且为纯平移——外部布局只决定容器整体位置，不改写成员相对坐标。
- **外部质点投影**：跨容器边界的边在子作用域内生成固定投影锚点，牵引所连内部项（子图朝向与包裹尺寸随之联动）；投影不占格、不参与死锁判定与插行列——即 §4.2 的影子节点机制。
- **容器不占布局位**：容器 AABB = 成员实占并集；链展开为蛇形网格，链内自带走线走廊。

## 7. 无向 vs 有向差异对比

| 维度 | 无向（'none'） | 有向（'TB'/'LR'） |
|---|---|---|
| 核心美学目标 | 均匀分布、多边形对称、紧凑无交叉 | 方向流动感、层级清晰 |
| 连线占位策略 | 全程零占位；阶段 5~7 统一走廊，阶段 8 避障走线 | 同左（跨层长边专项扩廊待办，§8） |
| 纵轴约束 | 自由寻优（由张力与环周长决定） | 软层级约束（R9 锚点 + 偏离罚，允许局部浮动） |
| 寻优搜索空间 | 二维网格广度搜索 | 以理想层级行为中心的局部偏置搜索 |
| 插行列策略 | 动态插行 + 插列 | 优先插横轴（TB 插列、LR 插行，保持层级行不乱） |
| 平滑与布线 | 网格解即最终解（无弛豫）+ 通道平行线偏移（风格策略） | 方向感由层级行锚定 + 方向罚构造保证 + 正交/贝塞尔走线 |
