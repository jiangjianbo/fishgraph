整个布局引擎的核心哲学在于：**"拓扑优先于几何，节点与布线解耦；离散网格定骨架，波纹生长成方阵，正交走线留通道"**。

## 最高原则：简单规则驱动，底层逻辑无例外（2026-09-26 定稿）

1. **布局只由少数局部规则决定**：张力（贴邻最近）、环周长奖励（封角）、
   环内方位分类（十字 < 45° < 杂角）、连线零共线（同起点两线夹角 ≠ 0）、
   连线零压线（线段不途经第三节点）、扫描序平局（先填满一行再开新行）、
   有向层级行（顺流）。每条规则都是局部、可独立陈述的，不依赖全局结构
   判断。
2. **无例外、无特例**：不针对特定图结构（星形/树/矩阵……）做结构识别与
   规则豁免。形状契约（严格矩阵、正方形、十字星、山形……）必须是规则的
   **涌现结果**；若某契约与某规则物理互斥（例：有向 TB 顺流与"十字星"互斥
   ——十字必有一条边逆流），则修改**契约**（改由无向模式验收或改契约形状），
   而不是给引擎开口子。
3. **引擎收敛**：2026-09-26 起 grid-undirected 为唯一主引擎（force-undirected、
   force-directed、group-undirected 已删除；circle 仅作为策略接缝的最小示例
   保留）。方向语义由 `direction` 参数（'none' | 'TB' | 'LR'）在同一流水线内
   承载：'TB'/'LR' 时粗布局换用层级引导放置（解环 + 最长路径分层 + 层级行
   锚定），其余阶段完全共用。

## 布局核心原则（Layout Principles）

无论是无向图还是有向图，算法遵循以下通用力学与几何原则：

1. **节点与布线两阶段解耦（Node-Routing Decoupling）**：布局核心关注**节点拓扑**，第一阶段连线完全不占用任何空间网格，仅作为“拓扑引力”引导节点近邻放置，消灭“线锁节点”死锁；后期通过网格插行列为连线拉出“走廊通道”，最后在连续坐标系下完成浮点布线。
2. **核心骨架优先（Core-First Placement）**：度数（连接数）越高的节点拓扑重要性越大。优先放置高度数节点以建立全局拓扑骨架，低度数节点与长尾后期挂载，避免边缘节点打乱全局结构。
3. **绝对无重叠与避让（Zero-Overlap & Avoidance）**：节点与节点之间严格禁止重叠，节点与连线也不能重叠，同起点/终点连线（逻辑直连线，不等于实际显示时候的连线）夹角不能为0。第一阶段网格碰撞检测简化为纯节点检测（`O(1)`），大大提高寻优吞吐量。
4. **跳数衰减斥力（Hop-Distance Repulsion）**：节点间的斥力基于图上的拓扑跳数（Shortest Path Distance）衰减。邻接不衰减，2~3 跳逐级衰减，远距离保持极弱斥力，以实现节点的均匀空间分布。（网格流水线口径：均匀分布由波纹生长 + 离散格占用构造保证，斥力不作为独立力学存在。）
5. **弹簧张力收缩（Spring Tension）**：连线天然具有像橡皮筋一样的弹性回缩力，距离越远拉力越大，使有连线关系的节点自然趋于紧凑。（网格流水线口径：体现为粗放置评分的张力项——到全部已放置邻居的曼哈顿距离和。）
6. **最小周长环/紧凑面约束（Min-Perimeter Ring Constraint）**：当新放置节点与已放置节点构成环（Cycle）时，优先将其放置在能使该环几何周长（或几何包围盒）最小的位置。由于已放置节点质量（Mass）极大，位置刚性高，新节点会被拉入最佳的紧凑面内，消灭长边穿透。
7. **质点化与通道式膨胀（Point-Mass & Channel Expansion）**：第一轮计算将所有节点（包括 Subgraph 容器）均降维为 `1 ✕ 1`无面积质点；后期通过网格插行/插列进行空间拉伸，既为节点物化真实尺寸，也为高密度连线预留走廊。节点真实尺寸由**初始化阶段的尺寸分级**确定（2026-09-23 定稿）：把所有节点的 px 盒宽/高**各自独立**做容差锚定聚类（同级对簇最小成员比值 ≤1.25），最小级上界即基准格宽/高（**宽高基准可以不同 → 矩形格**），各节点占用格数 = 盒尺寸 ÷ 基准格向上取整。宽高比本身定不出格数（2:1 可以是 2×1 也可以是 4×2），必须靠绝对分级；格数是整数，px 只作为中间量存在于内存计算中。（2026-09-27 落地为布局口径：格距 = 矩形基准格，节点物理尺寸 = 格数 × 格距，大小节点的尺寸比例真实化；分级与物理化由尺寸映射策略承担，见「三、尺寸映射策略」。）
8. **长尾卷起与逻辑聚类（Tail Roll-up & Hidden-Group）**：度为 1 的树枝/长尾以及度为 2 的长链在布局初期被收缩卷起为 `SuperNode`（即 Hidden-Group 逻辑聚类），骨架布局完成后再释放展开，避免长尾散弹破坏全局布局。

无向图布局的目标是**追求均匀分布、结构对称、最小面积填充与无交叉**。算法采用“图粗化 纯节点弹性网格布局 → 通道膨胀压实 → 连续浮点布线与平滑”四阶段流水线。

```
[1. 图粗化/卷起] ──> [2. 纯节点网格粗布局] ──> [3. 节点膨胀+通道扩容] ──> [4. 浮点布线与微调]
(长尾/Subgraph缩合)   (无线段占位/度数寻优)     (物化尺寸+插行列留通道)    (走廊Offset/连续弛豫)
```

### 1. 预处理与图粗化（Coarsening Stage）

- **长尾识别与卷起**：识别图中度数为 1 的叶子节点群和度数为 2 的长链，将其打包收缩为 `HiddenGroup`（卷起长尾），用估算体积的 `SuperNode` 替代。
- **Subgraph 容器质点化**：带固定形状的容器（Subgraph）将其视为一个 `1 ✕ 1` 的 `SuperNode` 参与宏观布局。质点化也是递归的，在主视图完成质点化之后，subgraph也要质点化，如果还有深层嵌套的subgraph，继续质点化，直到所有容器全部完成质点化。

### 2. 纯节点弹性网格粗布局（Node-Only Elastic Grid Placement）

- **节点排序（波纹连通生长）**：度数最高的节点作为种子占据网格中心，其余按 BFS 层序（到种子的跳数序）逐个出队放置——放置沿已填区域边界一圈圈向外扩张。全局度数降序会在对称图上形成多个朝相反方向生长的前锋、把矩阵图折叠（实测），故度数只决定种子与新分量的归属，不决定全局排列。

- **逐个网格放置（连线零占位）**：

  1. 将度数最高的首个节点放置在网格中心点 `(0,0)`。

  2. 后续节点放置时，以其已放置邻居的网格坐标为起点做 BFS 搜索。

  3. 评估候选网格点 `(x, y)` 的综合得分 `Score`：

     $$
     \text{Score} = w_1 \cdot \text{MinCyclePerimeterScore} + w_2 \cdot \text{SpringTensionScore}
     $$
     *此处的环周长与弹簧张力仅按节点间的曼哈顿距离计算，连线不作任何线段几何占位。*
     
     *纯网格流水线（grid-undirected）在此评分上追加可选的**环内方位分类**平局项：边的走向优先邻居的十字（水平/垂直）方位，45° 对角次之，杂角再次——只在张力同分的候选间裁决，距离维全权由张力承担。*
     
  4. 布局的时候依然要注意连线不能重叠，即 `A --> B`和 `A --> C`这种状态下，重叠出现 `A -->B--> C` 这种情况是不允许的。即不允许同起点的任意两个线的夹角为0（但是180度夹角是允许的）
  5. **节点压线禁令**：如果第三个节点会经过两个节点的直线连线（落在两节点连线线段的途经处），这个情况也叫压线，是不允许出现的情况——不管未来用什么风格划线（直线、折线、贝塞尔），"节点压边 / 边压节点"都必须在放置层构造性禁止。
  
- **动态插行列解死锁（Dynamic Grid Insertion）**：

  若搜索预算内无合格空格，或最佳候选的得分质量超过阈值（无向：最佳张力 > 2×邻居数+2；有向：层级偏离超过 2 行），触发死锁机制：在网格当前位置**动态插入一行或一列**（`insertRow` / `insertColumn`），推开周围节点，挤出新空间。**保障算法 100% 不死锁**。

### 3. 节点膨胀与通道扩容（Node Expansion & Channel Routing Expansion）

- **节点物化拉伸（中心对称膨胀）**：根据节点的真实尺寸（或 Subgraph 的实际宽高），把质点格膨胀为宽×高格的 AABB：质点格保持为 AABB 的中心格（奇数尺寸精确居中，偶数尺寸向左/上配平半格），扩张让位像推箱子一样沿四个方向**带内推开**相应元素——水平推挤只推目标行带内的元素，垂直推挤只推目标列带内的元素，其余行/列上的元素不受扰动，元素 AABB 全程完整、无重叠由构造保证。
- **长尾与 Subgraph 展开（折叠模式 `options.folding`）**：卷起的长尾（链）沿蛇形网格展开物化，Subgraph 内部节点由递归子作用域布局释放——外部让位以容器为原子单元整体平移，不改写子图内部相对坐标。
- **四方向网格压实**：推箱子式删除因插行列产生的多余无用空行空列，消灭大片空白。
- 在subgraph计算真实尺寸前，需要把嵌套的所有subgraph尺寸也计算出来，才能得到当前subgraph的尺寸。

### 4. 连续坐标浮点布线与微调（Floating-Point Routing & Continuous Smoothing）

- **坐标归一（作用域展开）**：Subgraph 的局部坐标由其子作用域布局独立决定，展开时作为刚性整体平移映射进全局网格坐标系；容器框 = 全部成员实占 AABB 的并集。外部后续的让位/扩容以容器为原子单元，只平移容器、不改写子图内部间距——子图坐标系与外部隔离，容器内部通道由子作用域自己的压实负责。

- **通道扩容（Channel Expansion）**：在节点行列之间**保留至少 1 个空行/空列作为“线缆走廊（Routing Channel）”**——压实把相邻占用行/列的空隙统一到 `channelMargin`（不足补出、超出回收）；按连线密度评估、在高密度区域额外再插行列（扩廊）待办。整体轴向拉伸完全不破坏已建立好的节点相对方位。

- **坐标映射**：将离散网格坐标 `(gridX, gridY)` 映射为连续平面坐标 `(x, y)`。

- **连续浮点数走线（Floating-Point Channel Routing）**：
  - 走线的时候，需要使用策略来确保走线的风格：连接点的位置确定，连接点的绘制，箭头的绘制，线的折角的绘制，线交叉的绘制，线本身颜色粗细线条的绘制，线的形状（直线、贝塞尔曲线、折线）、同一个通道内不同平行线的距离（重叠、保持间距）等。
  - 在拉伸出的通道走廊中，完全不受网格整数值限制，直接采用浮点数坐标计算连线拐点。
  
- **网格解即最终解（无弛豫）**：节点位置一旦物化不再被走线反向推开——无重叠由构造保证（带内推挤膨胀 + 通道压实），坐标写回后不做力学弛豫；力导向时代的“表面距离弛豫 10~20 步”（含表面有效距离 $d_{\text{effective}} = \Vert P_a - P_b\Vert - (R_a + R_b)$ 口径）已随唯一引擎收敛废弃。

## 二、 有向图布局算法（Directed Layout Pipeline）

有向图布局的目标是在保留无向图高效网格避让与通道布线的同时，引入**自顶向下（或自左向右）的逻辑流动感（Flow & Hierarchy）**。

有向图算法**共享无向图 90% 的底层架构（纯节点网格、通道拉伸、浮点走线）**，核心区别在于引入了**基于层级（Level）的“软层级约束（Soft-Level Constraint）”**。

```
[1. 解环与 MST 层级计算] ──> [2. 软层级纯节点网格寻优] ──> [3. 节点膨胀与通道插列] ──> [4. 浮力连续平滑与走线]
(确定节点 Level/y_ideal)     (度数优先 + y偏离惩罚)       (插入列走廊+释放长尾)    (重力场+通道浮点走线)
```

### 1. 拓扑解环与层级初始化（Level Assignment）

- **解环与 DAG 构建**：通过 DFS 识别有向图中的反馈边（回边，即破坏 DAG 性质的边），布局时临时忽略（不翻转、不参与分层与流向约束），将其转化为有向无环图（DAG）。

- **拓扑序最长路径定层级**：在 DAG 上按拓扑排序（Kahn）做最长路径分层 $\text{level}(v) = \max(\text{level}(u)+1)$，源点在第 0 层（实现取拓扑序口径，MST 为备选），计算出每个节点的逻辑层级 
  $$
  \text{Level}(V)
  $$

- **理想 Y 坐标设定**：为每个节点计算理想的行坐标初始值：
  $$
  y_{\text{ideal}} = \text{Level}(V) \cdot \text{RowSpacing}
  $$

### 2. 软层级引导的纯节点网格寻优（Soft-Level Guided Placement）

- **保留度数优先策略**：依然优先放置度数高的核心节点，保障全局骨架优先建立。

- **寻优起始锚点**：放置节点 $V$ 时，以 
  $$
  (X_{\text{neighbor}}, y_{\text{ideal}})
  $$
  作为 BFS 网格搜索的起点。

- **综合评估函数（带层级偏离惩罚，无线段干扰）**：
  $$
  \text{Score} = \text{Score}_{\text{base}} + w_{\text{level}} \cdot (y - y_{\text{ideal}})^2 + w_{\text{dir}} \cdot \text{DirectionPenalty}
  $$

  - **开阔区域**：$\text{Level}$  惩罚将节点像重力一样稳稳吸引在其所属的树层级 $y_{\text{ideal}}$ 附近，保证强烈的方向流动感。
  - **拥堵/冲突区域**：允许算法放弃部分 $y$ 层级约束（向上或向下挪动 1~2 行），优先保证无重叠与最小周长环，解决长边跨越与节点拥挤死锁。

- **一维/二维插列**：若当前层级行内网格拥堵，调用 `insertColumn()` 动态插入新列解死锁。

### 3. 方向感连续平滑与浮点走线（Directed Smoothing & Floating Routing）

- **浮点数正交/弧线布线**：在层级通道间使用连续浮点坐标进行走线；平行走线的浮点 Offset 分流由连线风格策略承担（同端点对平行边的法向横移已由 oblique 路径风格实现，跨边共通道分流待办）。
- **方向感由放置层构造保证（无弛豫）**：层级行锚定 + 方向罚使节点顺流落位（开阔处几乎总在同行，拥堵处允许偏 1~2 行）；坐标写回后不做“重力/浮力势能弛豫”（力导向时代的 15 步定向微调已随唯一引擎收敛废弃），走线方向与箭头朝向由端口主导侧与 waypoints 骨架保证。

## 三、尺寸映射策略（Metric Strategy，2026-09-27 定稿）

逻辑布局与现实尺寸的映射是一个独立的可替换策略（`LayoutOptions.metric`，
缺省 `default`，`registerMetricStrategy` 注册自定义，运行时
`layout.setMetricStrategy(name)` 切换）——同一策略在两个方向被消费：

| 方向 | 消费方 | 职责 |
| ---- | ------ | ---- |
| 正向（供布局） | 逻辑布局 | 节点度量（形状声明 ∨ 文字盒，文字按面积最小折行）→ 宽/高独立锚定聚类分级 → 矩形基准格 `cellW/cellH` + 各节点宽高格数 `gw/gh`（格数 = 盒 ÷ 基准格向上取整）——确定基准节点与各节点的标准尺寸 |
| 反向（供渲染） | 渲染出口 | 逻辑格解 → 世界坐标**可渲染图**（`layout.renderGraph`：节点 AABB / 容器实占 shape / 边 waypoints 纯数据）——渲染端拿自由坐标自行决定缩放与绘制，不感知网格 |

**矩形格口径**：1 格 = 最小基准盒（x 轴 `cellW`、y 轴 `cellH`，两轴独
立）；节点物理尺寸 = 格数 × 格距，大小节点的尺寸比例真实化；格密度由
基准格决定，`naturalLength` 不再缩放格距，节点间隙由 `channelMargin`
（格）控制。真正显示时在文字盒内叠加 padding 与行间距（行距系数待接）。

**扩展维度**（接口预留，默认实现 = 现状口径）：度量折行判据（面积最小；
周长平局待接）、行距系数、字体族测量（现 0.75 字宽比例估算）、聚类方式、
物理化相位与归零方式。

## 无向图 vs 有向图 算法核心对比

| **维度**           | **无向图布局算法**                                           | **有向图布局算法**                                           |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **核心美学目标**   | 均匀分布、多边形对称、紧凑无交叉                             | 明确的方向流动感（自顶向下）、层级清晰                       |
| **连线占位策略**   | **第一阶段完全不占位**（仅作为弹簧引力）；第二阶段压实统一 `channelMargin` 走廊，第三阶段浮点布线 | **第一阶段完全不占位**；二阶段压实统一走线走廊（跨层长边专项扩廊待办），三阶段正交/贝塞尔浮点布线 |
| **$y$ 坐标约束**   | **自由寻优**（完全由最小周长环与连线张力决定）               | **软层级约束**（以 $\text{Level}(V)$ 为初始锚点与惩罚场，允许局部浮动） |
| **寻优搜索空间**   | 二维平面网格广度搜索                                         | 以理想层级行 $y_{\text{ideal}}$ 为中心的局部偏置搜索         |
| **插行列策略**     | 动态插入空行 + 空列（节点与通道双重扩容）                    | **优先插横向轴**（TB 插列、LR 插行，保持层级行/列不乱），通道走廊由压实统一保证 |
| **物理平滑与布线** | 网格解即最终解（无弛豫）+ 通道平行线 Offset（风格策略）       | 方向感由层级行锚定 + 方向罚构造保证 + 跨层级正交/贝塞尔浮点走线 |
