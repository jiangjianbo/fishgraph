# 布局设计说明：无向分组布局（group-undirected）

> 状态：第一期已实现（`src/layout/group-undirected/`，注册名
> `'group-undirected'`）。旧 `force-group`（力场注入式分组）仍待按派生
> 接缝重写，与本算法是两条路线（见 §7）。

## 1. 设计动机与定位

分组布局的目标：图中的 subgraph / hidden-group 声明不再被算法无视，
而是成为布局结构本身 —— 组内成员作为一个模块聚在一起，组与组之间、
组与自由节点之间像普通节点一样排布。

实现路线是**深度优先的递归折叠**：任一层级的布局只看到「自由元素 +
子组单元」的扁平视图；组内部由**同一套流水线**递归布局（先内后外），
最后把组内部块平移映射到单元的最终位置。每个阶段 —— 质点排列、
带大小压实、力场弛豫、坐标系修正 —— 都以递归方式作用于组内节点。

基础引擎完全复用 force-undirected：粗布局（`coarsePlacement`）、
弛豫求解器（`RelaxationSolver` + 全栈力场）、坐标系修正。这些接口
全部是数组化的（elements/adj/edges 切片），组内成员子图切片即一张
独立的图 —— 这一点由 `tests/group-undirected.test.ts` 的前提验证
用例固化。

```text
layoutLevel(memberPool, childGroups):
  1. 深度优先：对每个子组 g → layoutLevel(g.members, g.children)
     递归返回后量测 g 的内部块 → 单元半径 = 块包围圆半径 + 包裹边距
  2. 阶段 1 质点排列：coarsePlacement 在本层视图上运行
     （单元占 1 格；压实按单元半径变距 —— 组被"巨大号的节点"表达）
  3. 阶段 2 力场弛豫：RelaxationSolver 跑在本层局部上下文
     （提升邻接：跨组连线连接到单元上；每层独立派生力学参数）
  4. 阶段 3 坐标系修正：cs.refine 按层执行
自底向上全部完成后：
  5. 自顶向下平移映射：组内部块 → 单元最终位置（纯平移，不缩放）
```

## 2. 分组折叠模型（compound.ts）

### 2.1 组森林

`buildGroupForest(store)` 把 subgraph 与 hidden-group 声明统一为组树：

- **subgraph**：容器节点（`LayoutSubgraphNode`）本身就是单元 —— 它已在
  `store.elements` 中，外部连线可直接以容器 id 为端点；
- **hidden-group**：布局期伪单元（`GroupUnitElement`，`LayoutElement`
  子类）—— 不进 store、不产生实体，布局结束后只留下成员的映射坐标；
- **嵌套**：组 B 的成员集合 ⊆ 组 A 的成员集合 → B 是 A 的子组（直接父
  取包含者中成员集最小者）；子组容器计入父组子树（无论是否显式声明为
  父组成员），随父组整体移动与提升；
- **重叠**：两组成员集相交且互不包含 → 抛错（一个元素只能折叠进一个
  单元，模糊归属必须是显式错误）；成员完全相同 → 重复声明抛错。

### 2.2 层级视图与连线提升

`buildLevelView(store, memberPool, childGroups)` 构造一层的扁平视图：

- 自由元素 = memberPool 中不属于任何子组子树者（保序在前），
  子组单元追加在后；下标即本层力学数组下标；
- **连线提升**：跨组连线 (member↔external) 变为 (unit↔external)，
  组内连线剔除，多条提升边去重为一条。两端均为自由元素的边复制原边
  （保留标签盒度量），提升边丢弃标签盒（提升后的连线不再有独立文字墙）。

折叠语义（v1 边界）：成员不直接感受组外力场 —— 组内外的耦合只有
「单元半径 = 内部块包围半径」与最终一次整体平移。

## 3. 阶段 1：质点网格粗布局 + 膨胀压实（复用）

`coarsePlacement(view.elements, view.adj, L)` 原样复用：度数优先连通
生长、环形扩搜、死锁插行列、删空行空列变距压实。单元在本层就是一格
质点；压实阶段读取 `getBoundRadius()` —— 单元半径即其内部块的包围圆
半径 + 包裹边距，因此：

- 组间、组与自由节点之间的间距按"最大半径"自动放大，跨层无重叠由
  与组内相同的构造不变量保证；
- 代价是圆口径对矩形块偏保守（方块越扁浪费越多）—— 已知边界，见 §6。

唯一扩展：`coarsePlacement` 新增 `ignorePlaced` 选项。组内层级在自身
局部坐标系中运行，成员残留的外层世界坐标不具备"用户定位"语义；不
忽略会把它留在局部布局之外，污染块包围盒。顶层仍尊重 placed。

## 4. 阶段 2：力场弛豫微调（每层独立求解器）

每层组装局部 `ForceContext`（提升邻接、层内边、`deriveParams(options,
本层规模)`、层内跳数矩阵）并独立弛豫到收敛（预算安全网 4000，与
force-undirected 同口径）。组的内外没有力场耦合 —— 不会出现容器-成员
振荡（旧 force-group 的已知问题）。能量/迭代观测口径取顶层求解器。

## 5. 平移映射（settleGroup）

全部层级完成后自顶向下映射：`δ = 单元最终位置 − 块当前中心`，把子树
成员整体平移 δ。两个细节：

- 块中心用**当前坐标**重新量测（子组成员与子组容器已被父组平移带动，
  父子平移在差值中自然抵消，恰好施加一次净平移）；
- hidden 子组的伪单元不在 store 中、父组平移带不到它，显式随父组平移。

映射后容器调用 `updateBoundsFromChildren` 刷新渲染口径半径（≤ 布局期
的保守单元半径）。

## 6. 第一期边界

- 圆口径保守：单元以包围圆参与外层，扁长块的角部留白偏多；
- 纯折叠：成员不跟随外部连线方向（组内布局不知道跨界连线的存在）；
- 提升边丢标签盒：跨界连线的文字不参与外层弛豫避让（渲染仍正常）；
- 组内成员的 `fixed` 语义受限：弛豫中不移动，但随组平移；
- 流水线构造期一次完成（grid-undirected 先例）：`step()` 不驱动动画，
  `refresh()/rebuild()` 整体重算。

## 7. 与 force-group（待重写）的关系

两者是分组的两条路线：group-undirected 是**结构折叠**（先内后外递归，
无力场耦合，本文件）；force-group 是**力场注入**（单层全量弛豫 +
包含墙/向心束缚/张力传导扩展，待按 `ForceExtensions` 缝重写）。
结构折叠适合"模块分明"的图；力场注入适合成员需要响应外部拉力的场景。
`tests/groups.test.ts` 中 skip 的用例描述的是后者的验收语义，保持 skip。

## 8. 测试（tests/group-undirected.test.ts）

1. **前提验证**：粗布局 + 弛豫求解器在成员子图切片上直接运行（用户
   步骤 1 的固化）；
2. subgraph：成员在容器内、外部节点在容器外、全体无重叠；
3. hidden-group：成员聚成模块（组内平均间距 < 组间平均间距）；
4. 嵌套 subgraph / hidden 嵌套于 subgraph：递归折叠、成员不出容器；
5. 确定性：同参数两次布局逐位一致；
6. 退化纯度：无组声明时与 force-undirected 结果逐位一致；
7. 组内 placed 不污染布局；重叠组声明抛错；
8. `detectHiddenGroups` 推断结果可直接驱动分组布局（集成冒烟）。
