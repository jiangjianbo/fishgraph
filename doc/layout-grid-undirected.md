# 布局设计说明：网格无向图（grid-undirected）

> 注册名 `'grid-undirected'`，实现于 `src/layout/grid-undirected/`。
> 是 `doc/布局核心原则.md` §4「流水线骨架」的落地实现，也是引擎的
> **唯一主算法**：**质点波纹粗布局 → 节点与文字中心对称膨胀（物化为格
> AABB）→ 膨胀后调整（消压线）→ 行列整理（收紧·对齐 → 走廊插入 →
> 通道压实）→ 网格 A\* 避障走线 → 通道车道分配**，全程整数格运算，
> 不经力场弛豫。
> 空间原语（A\* 走线、格 AABB 类型）内联于本目录（`grid-route.ts`
> / `grid-context.ts` / `space-types.ts`）。放置规则本体（波纹生长/
> 张力/环周长/禁令）见布局核心原则 §2.1 规则注册表与 §4.2，本文件只记
> 实现口径与关键细节。本文件的「阶段 N」编号 = 布局核心原则 §4 的
> 十阶段编号。

## 1. 设计动机与定位

grid-undirected 是引擎的**唯一主算法**：节点位置在离散阶段一次成型，
连线不占空间、只在自由通道格中寻路走线，节点位置一旦物化不再被走线
反向推开。

| 维度 | 口径 |
|---|---|
| 空间 | 整数格（全程） |
| 节点尺寸模型 | 格 AABB（`w × h` 格，物化为 `NodeView.w/h`） |
| 求解 | 构造期一次完成（`run()` 即返回收敛） |
| 边的输出 | 中心 + A\* 正交走线拐点（`InternalEdge.waypoints`） |
| 成行成列 | 通道压实后严格保证 |
| 确定性 | 全程固定规则，同输入逐位重放 |

粗布局（本目录 `coarse.ts` 的 `coarseGridPlacement`）只放置、不压实、
不写回坐标；grid 流水线消费放置产物进入膨胀。有向模式共用同一放置
主流程，仅替换放置美学钩子（见 §1.1）。

### 1.1 流动方向（direction：'none' | 'TB' | 'LR'）

- `'none'`（默认）：无向波纹放置（本文件 §2 的无向放置美学）。
- `'TB'` / `'LR'`：有向层级布局 —— `levels.ts` 解环（DFS 反馈边）+
  最长路径分层，`directed-placement.ts` 的层级引导放置（锚点钉层级行/列、
  层级偏离罚 W_LEVEL·(flow−level)²、方向罚、拥堵插列不动层级行）。
  所有边**顺流无逆边**。形状契约「5 点向心 → 顺流山形」即此模式的产物
  （十字星与顺流物理互斥，契约取山形——见布局核心原则 §2.2、§5）。

## 2. 阶段 2：质点拓扑粗布局（复用）

`coarseGridPlacement(elements, adj, naturalLength, heuristics)` 返回
`{ grid, posOf, cell, order }`：每格一节点的 `PointGrid`、每元素的格坐标、
格距、放置顺序。**矩形格口径**：格距 = 矩形基准格
（`options.cellW/cellH`，来自尺寸映射策略分级），`naturalLength` 不再
缩放格距；物化与物理化委托 MetricStrategy（见布局核心原则 §6.1）。
**波纹连通生长（BFS 层序）** + 环形扩搜评分（曼哈顿张力 − 环周长奖励 +
环内方位分类）+ 死锁插行列，**100% 不死锁**、全固定规则。连线不占位——
只有文字例外（第一期尚未实现虚拟文本节点，见 §8）。

放置的三条关键规则（2026-09-26 定稿，形状契约 5×5 严格矩阵/正方形的
直接来源）：

- **波纹生长（BFS 层序队列）**：候选集按到种子的跳数 FIFO 出队，放置沿
  已填区域边界一圈圈向外扩张。度数优先序会在对称图上形成多个反向生长
  前锋，把矩阵折叠（实测 5×5 → 6×6）；波纹序逐行填满成严格方阵。
- **扫描序平局**：得分相等的候选按 (gy, gx) 升序裁决（先填满一行再开
  新行），确定性不依赖环遍历细节。
- **环 0 候选**：锚点格（已放置邻居均值的取整格）为空时直接参评——
  两个邻居分居对角时均值格恰是张力最小的理想位，环搜从 1 起步会错过它。

方位分类（`directionClass`，无向模式启用）：边的走向优先落在邻居的十字
（水平/垂直）方位，45° 对角次之，杂角再次——**十字折扣只给贴邻**（距离
1），距离 >1 的十字方向属张力维已按格计价，不再享受折扣（否则「远距离
十字长边」零成本压过「近距离对角短边」，环类图被拉成共线，实测回归）。
能量 0 / 0.25 / 0.5，压在张力每格 1 之下，只在张力同分的候选间做环内
平局裁决；距离维全权由张力承担。

## 3. 阶段 3：节点与文字轴向膨胀（expansion.ts）

质点是 1×1 的，真实尺寸通过**格化 + 逐个扩张**物化。

### 3.1 格化

格化在流水线阶段 0（尺寸分级，`grade.ts` 的 `gradeBoxes`，由
`GraphStore.refreshGrades` 调用）完成：每元素的物理 AABB 尺寸 =
**文字阶梯盒**（`GraphStore.nodeBoxSize` → metric `measureBox`：有
标签节点尺寸全由 `estimateLabelBox` 的回绕盒决定——行数 × 每行最大
字符数，宽高比 `maxLabelAspect`（默认 4:1）约束回绕，声明形状不参
与；无标签节点用声明形状 circle 2r / ellipse 2rx×2ry / rect w×h；
subgraph 容器由 store 侧分流保留声明口径），按矩形基准格向上取整为
逻辑格宽高（宽/高基准独立、可以不同）：

```text
gw = max(1, ceil(nodeBoxWidth  / cellW))    gh = max(1, ceil(nodeBoxHeight / cellH))
```

格化是保守的（向上取整 + `1e-9` 容差），物化 AABB 保证 ≥ 文字盒。
膨胀（阶段 3）只消费分级产物 `gw/gh`，不做任何换算。

### 3.2 ExpansionGrid：AABB 占用网格

`PointGrid` 是"每格一元素"，膨胀需要"每元素占 w×h 格"。`ExpansionGrid`
以两张表为唯一事实来源：`anchorOf`（元素 → AABB 左上格）与 `sizeOf`
（元素 → AABB 格尺寸），占用格随时可由矩形导出，不存在格级簿记。

`expand(i, gw, gh)`：**中心对称 + 带内推挤让位**（奇数尺寸向两侧各扩
(gw−1)/2 格，质点格恰为 AABB 几何中心；偶数尺寸格上无精确中心，固定
向左/上多配一格配平半格）。推挤不是整行/整列插入：水平推挤的行带 =
扩张后的目标行区间，只推与行带相交、位于锚点对应侧的元素；垂直推挤
的列带 = 目标列区间，同理 —— 其他行/列上的元素不受扰动，消除扩张时
的全局连带平移。被推元素整体平移同一增量（组内相对位置不变，保序保
连续）；被推元素在带外的延展（高/宽元素）平移扫掠撞到的元素级联入
组，直至封闭 —— 落点必空、不越留置元素；横跨锚点格的元素不属任何
一侧，由正交方向推挤整体让位，元素 AABB 全程不被撕裂。之后锚点改写
为 AABB 左上格。质点格在全过程中不动，且 `anchor + floor(size/2)`
恒等于质点格（§6 的 A\* 中心格口径不变），与质点布局的"邻居贴邻"
语义兼容：扩张推走的正是 i 四周的邻居。

膨胀按 `order`（放置序）执行——后放置的节点在外缘，让位平移量小。

## 4. 阶段 4~7.5：膨胀后调整、行列整理与通道压实

**阶段 4：膨胀后调整（消压线）**——`deflectEdgeCrossings(g, edges,
skip)`：质点口径判定的连线零压线（R7）在元素加宽后可能失效（两端
中心格的 Bresenham 直线落进第三方 AABB）。对压线的第三方元素沿背离
连线的法向推离 1 格（`nudge`：推自身 + 扫掠级联让位，复用推挤级联
判定），迭代至无压线或达轮数上限（默认 8，有界尽力）；`skip` 为容器
集合（非折叠排除 subgraph 节点、折叠排除容器视图项），与走线障碍同
口径。折叠路径在作用域内以视图项执行，展开为纯平移不受影响。

**阶段 5~7**：膨胀后网格中留有大片空行/空列（插行列的让位副作用）。
整理与压实把布局**归一化为均匀走线走廊**。压实前有两步行列整理
（布局核心原则 §4.5）：

- `tighten()`（阶段 5·收紧）：间隔 >1 的相邻占用行/列收紧为贴邻，
  回收全部多余空行空列；
- `mergeLines()`（阶段 5·对齐）：把独居元素（所在列/行线上无其他
  元素锚点）吸附到邻近主线（锚点数 ≥2 的列/行线）——候选主线按距离
  升序尝试（平局取更靠近包围盒中心者），平移后与他者 AABB 重叠或
  扩大包围盒则放弃；迭代至不动点。可并线的散落元素由此对齐成列/
  成行（吸附落点按移动方向定对齐方向：向右移至少右对齐、最好中间
  对齐；向左移至少左对齐、最好中间对齐；上下同理——先试中心落点、
  再试行进前缘对齐落点，同宽时两者重合即锚点对齐）。

之后的归一化口径：

```text
相邻占用行（列）之间的空隙 = 恰好 channelMargin 格（LayoutOptions.channelMargin，默认 1）
  · 贴邻（空隙 0）→ 扩张出走线走廊（布局核心原则 §3.7 通道式膨胀、
    §4.5 行列整理与通道压实）
  · 大片空白 → 压缩回收（合并空行/空列，直到再并就小于 margin 为止）
```

实现是**单轴保序重映射**：收集占用坐标排序后，`new[k+1] = new[k] + 1 +
margin`。AABB 内部格全为占用列（间隔 0），重映射不影响其连续性；不同
AABB 的间隔 ≥ 1 格，无重叠由构造保证。压实后全局严格成行成列。

压实之后是**行列居中对齐** `alignCenters()`（阶段 7.5）：逐行、逐列
扫描，把该轴投影区间重叠的元素（行带/列带重叠，贴邻不算）传递归组；
组内元素目标 = 组带中心格 `round((bandLo+bandHi)/2)`，对齐**中心格**
（anchor + ⌊size/2⌋，与走线 A* 中心格同口径）而非连续中心——奇偶
尺寸不产生半格相位差。平移以 `tryShift` 逐格尝试（落点与他者 AABB
相交则失败），理想落点被占时向原位逐格回退、无空位放弃该元素；
单元素组跳过。同组元素经物理化格心吸附（§5）后中心逐位共线，
其连线为严格水平/垂直直线。

## 5. 阶段 9：物理化写回

AABB 中心映射为连续坐标（格 × 分轴格距，由 MetricStrategy.render
承担），整体平移使质心位于原点：

```text
center.x = (gx + ⌊gw/2⌋ + 0.5) × cellW + ox    center.y = (gy + ⌊gh/2⌋ + 0.5) × cellH + oy
el.w = gw × cellW                      el.h = gh × cellH
```

节点物理中心吸附**中心格**（anchor + ⌊size/2⌋）的格心，而非取几何
中心 (gx + gw/2)：奇偶尺寸的半格相位差被消除，阶段 7.5 同组元素的
中心经物理化后逐位相等、连线严格水平/垂直（走线直线升级的端点同取
中心格格心）。质心归零按吸附后的中心均值计算。

写回 `elements[i].x/y/w/h`——`w/h` 是新增的可选输出（`NodeView.w/h`），
渲染方按「中心 + 半宽高」得到包围盒；连续布局不产生这两个字段（用 `r`
包围圆）。`coordinateSystem` 修正不适用：网格解本身就是格点。

## 6. 阶段 8：网格 A\* 避障走线（泛型化层消费）

走线委托给 `GridSpaceContext.routeEdge(source, target, obstacles)`
（本目录 `grid-route.ts` 的 A\*）：4 邻域正交寻路、状态 =
(格, 进入方向)、代价 = 步数 + `turnCost` × 转向 + `hugCost` × 贴边相切
数（曼哈顿启发可采纳）。贴边 = 车道线与偶数格尺寸盒物理越界边重合
（偶数格盒中心吸附中心格格心，物理边界落在行进侧相邻格的格心线上，
沿该格心线走线物理上贴着盒边——连线成节点轮廓切线的根因）；贴边代价
（默认每相切盒 2 格）让等价路径优先走通道中央，通道容量不足时照常
贴边兜底。搜索界从「端点 + 障碍包围盒外扩 margin」起步逐轮加倍，
**无可行路径返回 null**（不静默降级）。路径经三格窗口压缩为拐点序列。

策略侧在首轮逐边寻路后做二轮**同端点同向共线对齐**（`routeInCells`）：
共享端点且端口同侧（同一 dominantSide 分组键）的 sibling 边，以首轮
骨架占用的格线为共线参照，通过 `laneBonus` 车道折扣（每步 0.25 格，
引擎钳 ≤ 0.5、启发按 1−rate 缩放保持可采纳）重寻路 —— 同向边尽量延长
共用干线后再分岔（共线距离越长越好）；折扣小于单位步长，纯绕远永远
不胜出；exact 直线（正对位升级 / 降级兜底）不重寻路，其骨架线仍作为
参照输出。

策略侧的约定：

- **端点** = 两端「对端主导侧」的边界中点格（与渲染端口同一
  `dominantSide` 口径）—— 骨架天然贴端口方向出入，两端对位时退化为
  直线；1×1 盒即中心格；
- **障碍** = 全部非容器节点的格 AABB（**含两端自身**，仅起终点格豁免
  —— 首末段因此必然沿端口法向穿出/进入，不会折回节点内部）；走线
  **不修改节点位置**——连线不占空间，只在自由通道格流转；
- **输出**：`InternalEdge.waypoints` = 首尾（两端端口侧锚点格中心的
  精确物理坐标）+ 中间拐点（格中心，物理坐标由 MetricStrategy 分轴
  换算 `(g + 0.5) × cellW/cellH`）。无可行正交路径（贴邻节点顶死
  出口）时降级为两端直线两点。

渲染端（`EdgeStyleRenderer`）的端口朝向优先取骨架首/末段的实际行进
方向（无骨架回退中心连线方向），端口面与走线出入方向恒一致；正交
折线路径在端口处 breakout 接入并合并共线碎段；末段短于端帽长度
（`minStub` = breakout 与端帽 tipLength 取大）时由
`enforceEndStub` 外推到恰 `minStub`（肘点重组保持全折线正交，肘臂
与来路反向会折出 180° 回折钉时放弃——这类几何由阶段 8.5 的端点盒
约束在骨架侧避免）。端点锚定的进一步精化（边框交点、同侧多边等距
分布）是渲染层的后续工作。

## 6.5 阶段 8.5：通道车道分配（lane.ts）

A\* 逐边独立寻路、互不感知：同一通道格线上的平行段会重合。车道分
配在骨架定型后、物理化之前做一次纯几何的跨边分配——**骨架拓扑完全
不变，只计算每中段的法向偏移量（格单位）**：

- **登记**：cells 压缩为拐点序列（`compressCorners`，强制保留首末端
  点使端口贴边段恒 1 格），中间段按轴登记到格线（垂直段 → 列线、
  水平段 → 行线）。首末段是端口法向贴边段，偏移恒 0（终点垂直）；
  与首/末段同轴同线的中段（端口延伸段）同样恒 0——偏移会与端口段
  错轴断裂；
- **单位**：同一条边在同一条格线上的全部区间合并为一个分配单位
  （U 形绕行两段共享同一车道——同边同通道位置固定）；
- **车道簇（端点关系定共用）**：恰共享一个端点的边（sibling）在重
  叠段聚成同簇——倾向共用路径，簇内全程共享同一车道偏移；两端都相
  同的重合边（bundle）与无端点关系的边照常错开——bundle 的错开覆盖
  全部登记段，仅端口法向贴边段物理汇聚于端口（同端点对端口分散是渲
  染端的后续工作，§6）；
- **冲突组**：同格线上区间重叠（相触即冲突，相交不冲突）的**簇**按
  并查集分组（格线内连通、不跨线；簇是占位原子，同簇单位必须一起参
  与错开，否则共享车道会被拆散）；
- **分配**：组内按簇（代表 = 簇内最长边）总长降序（长线相邻共存时
  间最长，优先挑位；平局按簇内最小边序保证确定性）从中央向外蛇形取
  等差位置——长线最贴近格心线（通道中央），簇内单位共享同一车道；
- **交叉嵌套约束**：端点完全不同的两边（`other` 关系；sibling/bundle
  允许共线共用）在共用端点行/列上各有一段反向延伸的正交段时（单位登
  记时记录各段两端的正交延伸方向），两拐点必须嵌套——向 + 偏移轴延
  伸者取更大槽位，槽位差 = 组内间距（最小空隙），否则两端正交段在共
  用行/列线上交叠。有约束的组改按拓扑序（rank 优先，成环按 rank 序
  破开兜底）铺升序槽位，无约束的组保持蛇形居中不变；
- **可用偏移区间（障碍感知）**：盒的物理边界相对格系统有半格相位
  （中心吸附中心格格心：奇数格盒边界 = 格线，偶数格盒边界 = 格心
  线，见 `boxExtent`）。偏移线与行/列区间重叠的障碍盒物理边界保持
  安全距 0.25 格；与**所属边自己的端点盒**保持半格（渲染端
  breakout/箭头接入长度，第三方盒贴近时 0.25 间距会把末段压到短于
  箭头且外推与来路反向构成回折）。有真实约束的一侧用真实边界（不
  与名义半宽取交——贴格心线的盒一侧推开偏移后，另一侧的开阔空间不
  应被遮蔽），无约束的一侧退回名义通道半宽留安全距，并保证足以容
  纳组内均分铺放（行/列区间不重叠的盒与线永不相交，兜底放宽不引入
  穿盒）；
- **物理化**：`LayoutRoute.laneOffsets`（每段偏移，格单位）由
  metric/default 的 render 换算为拐点处相邻段车道线的交点（垂直段
  固定 x′ = 格心 + δx、水平段固定 y′ = 格心 + δy）——零新增拐折、
  全折线保持正交。独占通道的边不设 `laneOffsets`，坐标逐位不变。

## 8. 折叠流水线与子图投影（folding）

`options.folding` 开启后走折叠流水线：链 / subgraph 折叠为视图项 →
各作用域（root + 每容器一个作用域）独立完成「质点放置 → 膨胀 →
消压线 → 行列整理与压实」（§4~§4 全阶段，容器视图项不入消压线判定）
→ 纯平移展开 → 物理化 + 走线。

- **子图坐标系隔离**：让位与插空行列只发生在作用域内部、以视图项为
  原子单元（容器 = 单个 item）；展开是唯一落位动作且为纯刚性平移，
  外部布局只决定容器的整体位置，不改写成员相对坐标（回归测试：
  外部增删节点 / 插空行列，成员相对坐标逐位不变）；
- **外部质点投影**：跨容器边界的边（一端在容器内、一端在外）在子作
  用域内生成**固定投影锚点** —— 位置 = 外部质点在 LCA 作用域放置帧中
  相对容器质点的偏移（两遍放置校正：第一遍求质点包围盒中心 ≈ 容器
  质点，第二遍带锚点放置）。投影只通过 `CoarseHeuristics.anchorTerm`
  牵引所连内部项（子图朝向与包裹尺寸随之联动），不占格、不参与死锁
  判定、永不参与插行列推挤 —— 投影自身坐标在子图布局过程中不变；
- **链内走廊**：链形状判据按 gap=0 蛇形网格评估（面积 → 周长 → 横
  向），物化时由 `chainFootprint` 按通道宽插入链内走线走廊，随链整体
  平移、不被外部改写。
