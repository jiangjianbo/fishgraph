# 布局设计说明：力导向布局（force-directed）

> 默认布局算法，注册名 `'force-directed'`，实现于 `src/layout/force/`。
> **纯粹性约定**：本算法不含任何 group（subgraph / hidden-group）语义；
> 分组力学由其派生策略 **force-group**（注册名 `'force-group'`，实现于
> `src/layout/force-group/`，继承本算法）通过扩展点注入，见 §8。
> 本文采用总分结构：§1 先给出人能直接理解的**布局规则**（力规则、避让规则、
> 过程规则），后续章节逐条展开它们如何实现。它对架构的接缝关系见
> [architecture.md](./architecture.md) §7。

## 1. 布局规则总览

算法只做一件事：让所有节点在一组简单的力学规则下达到平衡。规则共十条，
分三组——**力规则**（谁推谁拉）、**避让规则**（什么不能压什么）、
**过程规则**（怎么从初值走到平衡）。后面的公式与模块都只是这十条的实现。

### 力规则（谁推谁拉）

| # | 规则 | 一句话说明 | 详见 |
|---|---|---|---|
| R1 | 节点互相排斥 | 靠得越近推得越猛（贴上=强制分离，**绝不重叠**）；间距超过 2×自然边长就完全不推——脱离接触互不干扰，整图自然趋紧凑 | §4 |
| R2 | 连线是橡皮筋 | 相邻节点互相拉，**越长拉力越大**；张力默认校准为：无干扰时平衡间距恰为自然边长 | §4 |
| R3 | 无关系轻微聚拢 | 没有连线关系的节点之间只有很弱的引力（默认朝质心收拢），让孤立点和孤立分量不会散到天边 | §4 |
| R4 | 关系越远推得越轻 | 斥力按图上跳数衰减：邻接不衰减，2~3 跳逐级衰减，3 跳以上几乎不推；**例外**——贴身防重叠永不衰减（防穿越是硬规则） | §7 |

### 避让规则（什么不能压什么）

| # | 规则 | 一句话说明 | 详见 |
|---|---|---|---|
| R5 | 节点不压线、不压字 | 节点压到连线或边文字上会被强斥力推开，**连线两端同步让路**；边文字多大就把两端撑开到恰好容纳，长文字按最小面积自动折行 | §4、§7 |
| R6 | 交叉有代价 | 一条线每多一个交叉，它就收缩得更努力，且每个交叉抬高布局总能量；可选开关：两条线贴近时直接互相排斥，把交叉在力学上挤开 | §4、§7 |
| R7 | 组是实体 | 无形状的组（hidden-group）成员向组质心聚拢；带形状的组（subgraph）成员被「关」在容器内，容器对外表现为一个大节点（**仅 force-group**） | §8 |

### 过程规则（怎么达到平衡）

| # | 规则 | 一句话说明 | 详见 |
|---|---|---|---|
| R8 | 初始即平面 | 度数高的节点先排在中心（树中心为根），子树按规模扇形展开——树/森林的初值本身就是**无交叉**的 | §6 |
| R9 | 能量只降不升 | 分阶段弛豫（先散开 → 挂线 → 避让 → 算文字），每步沿力方向移动、能量上升就折半重试；所有节点合力≈0 或位置实质不动即收敛，无摩擦、必然停 | §3、§5 |
| R10 | 先自由后吸附 | 力学平衡完成后，可选把坐标吸附到网格等坐标系——修正是最后一步的「排版」，不再回头改力学 | §9 |

**共同推论**（不需要额外机制）：均匀键合的环状结构自然趋于正多边形；有限
作用域斥力 + 弱引力共同把覆盖面积压向最小。

**调参直觉**：想更紧凑 → 加大 R3 的引力或 R2 的张力；想更松 → 加大自然边长；
交叉消不掉 → 打开 R6 的线间斥力（仅稀疏图）；大图变慢 → 见 §11 的自动降级。

## 2. 设计目标与模块分工

把 §1 的规则变成可收敛的计算，有两个硬要求：

- **所有力必须是同一个能量泛函的梯度**（力 = −∇E）——R9 的「能量只降不升」
  完全依赖它（架构决策 4）；
- **满足 README 的排列原则**（度数高者居中、短程强斥力、交叉受罚、环均匀……）
  ——§1 的十条规则即其浓缩。

模块分工（策略内部的三段式）：

```text
strategy.ts   调度与生命周期：参数派生 → 初值 → 分阶段弛豫 → 派生精修缝 → 坐标修正
solver.ts     RelaxationSolver：信任域 + 回溯线搜索的单步弛豫
forces.ts     力场计算（物理核心）：精确 O(n²) 与 Barnes-Hut 两路共享力项
init.ts       初始摆放：bfs（平面扇形，默认）/ circle / grid / random
hops.ts       跳数斥力衰减矩阵（拓扑导出）
crossings.ts  边交叉计数（扫描线 + 预算回退）
quadtree.ts   Barnes-Hut 四叉树（双树遍历）
spatialgrid.ts 均匀空间网格（避让候选对）
```

派生策略 `src/layout/force-group/`（继承本策略）：

```text
strategy.ts   ForceGroupStrategy：组内精修调度 + 聚集系数派生 + region 钳制
groupForces.ts group 力学：聚集束缚、成员锚定、斥力豁免、张力传导（实验）
```

## 3. 总体流程（规则 R9 的调度骨架）

```text
构造：
  deriveParams()      布局选项 → 力学常数（全部以 naturalLength = L 标定）
  applyInitPlacement() 初始摆放（尊重显式定位节点，决定收敛速度与平面性）
  ForceContext        组装力场求值所需的一切引用与派生数据
  RelaxationSolver    弛豫求解器

run(maxIterations=1500, staged=true)：
  ┌ stage 0 (35%)  只有节点力场：斥力 + 弱引力/调和约束     （R1/R3）
  ├ stage 1 (30%)  加入连线：橡皮筋弹力、交叉收缩           （R2/R6）
  ├ stage 2 (20%)  加入避让：边-节点软墙、边文字软墙        （R5）
  ├ stage 3 (15%)  节点文字生效（有效半径变大，重新弛豫）   （R5）
  ├ 派生精修缝      force-group 在此执行组内精修（有组时）   （R7）
  └ 坐标系修正      cs.refine()：free 恒等 / grid 网格吸附   （R10）

每阶段用掉总预算的比例份额（可提前收敛）；staged=false 时全量力场一步到位。
```

阶段化不是美观考虑：阶段 0 先让斥力把团块分开，连线加入时不会把尚未展开的
结构硬拉到一起；文字最重（有效半径变大意味着所有间隙要重排），放在最后。

## 4. 物理模型（力规则 R1~R3 与修正项 R4~R6 的公式化）

记节点 i、j 的**表面间隙** `g = 中心距 − rᵢ − rⱼ`（不是中心距），
`m = mᵢ·mⱼ`，L = `naturalLength`。所有常数在 `deriveParams()` 一处导出：

| 力 | 势能 E / 力 F | 作用域 | 规则 | 设计意图 |
|---|---|---|---|---|
| 节点斥力（远程墙） | E = ½k_r·m·σ·(1/g−1/R)²，F = k_r·m·σ·(1/g−1/R)/g² | g < R = 2L | R1 | 截断势：g→0 主项回归 k_r/g³（近距陡增），g = R 处能量与力同时光滑归零（C¹）——脱离接触即互不干扰 |
| 近程防穿越墙 | 同型势，k_near = ½k_r，作用域 0.8L | g < 0.8L | R1/R4 | **永不随跳数衰减**：远端节点可以不互相推挤，但不能互相穿越（否则树布局产生交叉） |
| 接触弹簧 | 在 gFloor 处线性化 + 二次硬化 | g < gFloor ≈ 1%L | R1 | 防重叠不可妥协：穿透越深推力越大，E 与 F 严格一致（线搜索总有效） |
| 连线弹力（橡皮筋） | F = τ·(k_a/L³)·μ_e·m·g，E = ½·同系数·g² | 仅相邻对 | R2 | 线性弹簧，越长拉力越大；g→0 拉力消失（压缩交给斥力）。**τ=1 时平衡间隙恰为 L**（k_r 按此校准） |
| 弱引力（pairwise） | F = k_w·m/g² | 非相邻对 | R3 | k_w ≪ k_a；陌生人平衡距饱和于斥力作用域。gFloor 以下截断为常力防发散 |
| 调和约束（centroid，默认） | F = k_harm·m·d（朝对方） | 全对 | R3 | 平行轴定理下等价「到质心的简谐束缚」，合力/合力矩恒零；按节点数归一，总强度与规模无关 |
| 边-节点避让 | F = k_en·(ρ−h)/ρ，E = ½k_en·(ρ−h)²/ρ | 节点表面距线 < ρ = 0.15L | R5 | 线性软墙，全压约键合力 30 倍；反作用按垂足重心坐标分摊给线两端（**线会让路**） |
| 边文字软墙 | 同型，k_lbl，margin = max(2, 4%L) | 节点距文字盒 < margin | R5 | 文字盒 = 精确矩形 SDF；文字多大就把两端撑开多大；对边的**自己的端点同样生效** |
| 线间避让（opt-in） | 采样点-线段软墙，k_ee = 30 力单位，d_ee = 0.35L | 两线中心距 < 0.35L | R6 | 采样点是端点线性插值 → 力按插值权重分摊回端点，力 = −∇E 严格成立 |
| 交叉收缩乘子 | μ_e = 1 + λ·X_e，λ = crossingShrink | — | R6 | 每条边每交叉一次，弹力劲度放大 (1+λ) 倍：交叉越多的线收缩越努力 |
| 交叉能量罚 | 总能量 + crossingEnergy·(k_a/L)·ΣX | — | R6 | 分段常数势垒（无梯度）：交叉事件即能量台阶，由线搜索的能量比较回避交叉 |

关键设计约定：

- **力与能量必须同源**（架构决策 4）。交叉计数每次力场求值时按当前坐标重算，
  力与能量用同一组计数——「分段保守」：交叉事件之间严格保守，能量单调性不受
  影响。因此避让软墙**不钳制穿透深度**（钳制会让力与梯度不一致，线搜索全线拒绝）。
- **两条斥力墙叠加仍保守**：远程墙与近程墙同为截断势，和的梯度 = 梯度的和。
- **subgraph 的容器与其成员之间斥力为 0**（σ = 0，force-group 经
  `repulsionExempt` 扩展点声明）：成员位于容器内部是期望状态，不算穿透；
  防重叠改由成员间互斥 + 包含墙保证（§8）。
- 完全重合的节点对用 `jitterDirection` 的确定性伪随机方向弹出（避免 NaN、
  保持可复现，架构决策 6）。

## 5. 求解器（规则 R9 的实现，RelaxationSolver）

每一步：

1. 在当前位置求力场与总能量（惰性求值，外部改动坐标后由 `invalidate()` 失效）；
2. 试探位移 = 力方向 × 比例步长，整体截断到信任域 `maxStep`；
   远场漂移下限：|F| 显著时位移不低于 `driftRatio × stepSize`（随力残差在
   收敛带内淡出）——弱引力 ∝ 1/g² 在远处衰减到极小，纯比例位移会让孤岛
   合并得极慢；
3. **回溯线搜索**：能量上升则位移折半重试（至多 8 次）。力方向即负梯度方向，
   总能找到下降步长——这是「必然收敛」的机制保证；
4. 信任域自适应：满步接受则倍增（快速恢复），线搜索收缩则按 λ 收缩但不低于
   `maxStep × 5%`（防「每步纳米级爬行」）；
5. 收敛判据（三者任一）：
   - 力残差 `max|F|/forceUnit < forceEps` 连续 5 步（「每个节点都停在合力为零处」）；
   - 位移衰减平均 < 0.01px 且已迭代 60 步以上（布局实质停止移动）；
   - 线搜索在所有缩放下失败且步长地板命中 24 次（数值精度下的局部极小）。

判据阈值由 L 派生（如 `forceEps ≈ 0.5/L`），与线间避让的满额力（约 30 力单位）
之间隔多个数量级——交叉态不会被误判为平衡。

## 6. 初始摆放（规则 R8 的实现，init.ts）

**'bfs'（默认）—— 平面扇形展开，三遍式：**

1. 每个连通分量 BFS 建生成树；根取「树中心」（剥叶法，偏心距最小者中度数
   最大）——结构中心先放，放射形态与直觉一致（度数高者先排）；
2. 自底向上统计子树规模；
3. 逐锚点放置：锚点的角窗按孩子子树规模比例切分，孩子放在角窗内的环带上
   （半径 ≈ max(1.15L, 0.85L·子树规模/2π)，加确定性抖动破对称）。

子树角域递归不相交 ⇒ **树/森林的初值就是平面嵌入（无交叉）**。这一点是
刻意的架构配合：跳数衰减关闭了远程斥力后，交叉已不能靠斥力自动拉开，
「初值无交叉 + 能量单调下降 + 交叉能量罚」共同保证弛豫全程无交叉
（`tree21.test.ts` 验收）。展开中心必须取自己的角窗中心而非「背向父」方向，
否则宽子树的窗会横跨父边——此坑已在实现中修掉并注释。

多分量时，第 2..n 个分量根沿黄金角（2.399963 rad）螺旋排布，尺度与引力
模式的真实平衡尺度一致（centroid：调和束缚的 blob 尺度；pairwise：弱引力
与截断斥力的平衡间隙）。

**其余模式**：`circle`（半径 √n 增长的圆环 + 槽位抖动破对称）、`grid`、
`random`。全部尊重 `placed` 标记——用户显式定位的节点不动，且可作 BFS 锚点。

## 7. 拓扑派生与加速结构（规则 R4/R6 的高效实现）

### 7.1 跳数斥力衰减（R4，hops.ts）

- 图拓扑（与坐标无关）决定每对节点的 BFS 最短路 h，预计算 n×n 乘子矩阵：
  σ = 1（h ≤ 1，键合物理不变）→ decay^(h−1)（h = 2..3）→ unrelatedRepulsion
  下限（h > 3 或不同分量）；
- 衰减只作用于远程墙；近程墙与接触弹簧永不衰减（防穿越/防重叠是硬规则）；
- **规模上限 3000 节点**：超出整体停用（σ 恒 1），O(n²) 矩阵不失控
  （架构决策 7）；
- 矩阵仅在图结构或衰减系数变化时重建，力场求值只查表。

### 7.2 交叉计数（R6，crossings.ts）

- 扫描线（按 x₀ 排序 + 活跃集）统计每条边与**不共享端点**的边的严格相交
  次数（端点搭接、共线重叠不算），接近 O(E log E + K)；
- **预算回退**：单次计数超 80k 对测试即返回 null，调用方回退为「无交叉」
  （μ_e 全 1、罚为 0）——特性在大图上自动停用而不是拖垮求解器
  （架构决策 7）。

### 7.3 Barnes-Hut 四叉树与空间网格（性能基础设施）

- 节点-节点力走四叉树（`theta` 张开判据，默认 0.9），**双树遍历**保证每个
  无序对/节点×远块恰好访问一次：旧实现「每个节点各自查询」会让同一对节点
  一个方向逐点算、另一个方向块聚合，混合近似破坏保守场，线搜索找不到下降
  方向（收敛到重叠死局）——此失败模式记录在模块头注释，是架构决策 4 的
  直接证据；
- 节点 × 远块：能量按「块质量集中于质心」的聚合势计一次，p 受完整聚合力，
  反作用以「每单位质量常力」挂在块上，遍历结束由 `distributeReactions`
  摊派——力与能量仍是同一泛函的精确梯度；
- 张开判据用**块到块最短距离**（非质心距）：短程力核下质心距会把紧挨查询点
  的块误判为远块，整块聚合吞掉近距斥力导致重叠不被推开；
- 边/标签 × 节点的避让候选对走均匀空间网格（stamp 去重），网格边长与避让
  影响半径同量级；线间避让复用同一网格（插入边包围盒后 ei<ej 去重遍历）。

## 8. 组约束（规则 R7 的实现：派生策略 force-group 对分组模型的解释）

**本算法（force-directed）不含任何分组语义**——声明了 subgraphs/hiddenGroups
的图请选 `'force-group'`。底座把分组声明**物化**：subgraph →
`LayoutSubgraphNode` 容器节点（参与碰撞）、hidden-group → `ClusterConstraint`
质心束缚（架构决策 5）；force-group 是这些物化结果的唯一消费者，通过基类的
受保护扩展缝注入全部组力学（`ForceContext.extensions` + 精修/region 钩子），
基础力场只负责在固定时机调用，不解读其内容：

| 组类型 | 力学实现（扩展点） |
|---|---|
| hidden-group | `extraForces` → `ClusterConstraint.applyForces()`：成员到组质心的简谐束缚（强度 = `attractionStrength` ?? `groupCohesion`，按成员数归一）；整体收敛后 `refineLayout` 钩子执行**组内精修**：冻结全部组外节点（含 subgraph 容器），只弛豫组成员；若精修使成员包围盒变化超 15%，视为束缚过强，再触发一轮整体弛豫 |
| subgraph | 三件套：① `repulsionExempt`：容器与成员间**斥力豁免**（成员在容器内是期望状态）；② `extraForces` → 成员到容器锚点的束缚（把成员拢在容器内）+ **容器半径自适应**——每轮力场求值末尾 `updateBoundsFromChildren()` 把容器 r 撑到 max(baseR, 覆盖全部成员 + padding)，容器随成员长大；③ `coordinateRegion`：格点吸附时成员区域钳制在容器内切区 |

实验项 **张力传导**（`tensionConduction`，默认关）：跨容器边的弹力按有界
比例传导给成员所属的容器，使容器朝连接方向靠近（`edgeAttraction` 扩展点）。
已知问题：简单传导与容器互斥/弱引力平衡后仍可能振荡，需要专项的
「容器间引力 + 阻尼」设计（`mermaid-subgraph.test.ts` 有「已知边界」用例
钉住现状）。

## 9. 坐标系修正挂点（规则 R10 的实现）

弛豫与精修完成后，策略构造 `CoordinateNode[]`（坐标、半径、fixed、以及
派生策略经 `coordinateRegion` 钩子提供的吸附区域——force-group 给 subgraph
成员 `{ anchorId: 容器, rIn: 容器内切半径 }`），调用
`cs.refine(nodes, { lattice })`，再把修正后的坐标写回 store。

- `lattice` = `gridSize > 0 ? gridSize : naturalLength`（0 = 跟随自然边长）；
- 'free' 恒等；'grid' 就近吸附 + BFS 环形扩搜冲突消解，保证吸附后不重叠，
  region 成员的搜索窗钳制在锚点**吸附后新位置**的包含区内；
- 换坐标系只影响这一步，与算法选择正交（架构 §7 影响点 6）。

## 11. 复杂度与规模边界

| 路径 | 复杂度 | 边界行为 |
|---|---|---|
| 节点-节点力（BH） | O(n log n)/步 | theta 越小越精确越慢 |
| 节点-节点力（exact） | O(n²)/步 | 小图/参考实现 |
| 避让候选对 | 网格加速，≈ O(n + E) | — |
| 交叉计数 | O(E log E + K) | 超 80k 预算回退为无交叉 |
| 跳数矩阵 | O(n²) 预计算 | > 3000 节点停用 |
| 收敛 | 能量单调 + 三重判据 | maxIterations 兜底（默认 1500） |

`layout.test.ts` 覆盖 n=2000 压力测试：有限时间完成、无 NaN、无重叠。
